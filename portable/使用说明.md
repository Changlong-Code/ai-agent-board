# AI Agent Board 离线基础版 0.1.1

## 启动

1. 完整解压 ZIP 到固定文件夹。
2. 双击 `Start-Agent-Board.cmd`，或用 Chrome / Edge 直接打开 `index.html`。
3. 无需安装 Node、Git、Python 或购买 API。关闭网页即可停止。

需要支持 dialog、File.text、replaceChildren 的现代浏览器。不能保证 Windows 1909 自带的旧浏览器可用，目标电脑仍需实际试运行。

## 功能

创建和重命名项目；项目间任务隔离；创建、编辑、删除任务；待办/进行中/待验收/已完成四列；拖放和状态菜单；高/中/低优先级；搜索筛选；归档与恢复；JSON 导出和导入；异常备份校验与损坏数据保护。

本包是独立的离线基础看板，不是原版 React/SQLite 完整程序的 Windows 移植。AI 执行、Codex/Claude 接入、终端、自动开发和原版数据库导入尚未实现。移动到“进行中”只改任务状态。

## 数据和备份

数据保存在当前浏览器配置的本地存储中，**不是自动写入解压文件夹**。固定 HTML 的文件位置与浏览器；换位置、浏览器配置、无痕模式、清理浏览器数据可能导致看不到旧任务。

每次重要修改后点击“导出备份”，确认浏览器已下载 JSON。备份包括全部项目、任务及归档。换电脑时先导出，再在新环境导入。导入会替换当前离线版数据，应先备份；只有本离线版格式受支持。

保存失败时不会应用修改。存储损坏时禁止覆盖，可下载原始损坏数据并导入有效备份；不会自动清空损坏存储。每次保存前保留上一份原始存储。该副本仍属于浏览器存储，不能替代下载备份。

检测其他窗口写入或清空数据后，暂停本窗口保存与导入，请刷新再操作。写入前还会比对保存快照。此保护不是跨窗口事务锁；建议同一时间只用一个编辑窗口。离线版不会读取或修改原项目数据库、Git 仓库或账号信息，也不执行任务文字中的命令。

## 卸载

先导出备份，再删除解压文件夹即可。浏览器存储不会被程序自动删除。
