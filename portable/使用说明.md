需要本地项目接入时，请阅读压缩包根目录的 PROJECT_CONNECTION_CN.md，并运行 Start-Connected-Board.cmd。直接打开当前 HTML 只能使用离线与复制交接功能；本地连接功能需要 Node.js 服务和已安装、订阅登录的 CLI。

# AI Agent Board 离线基础版 0.1.2

## 启动

1. 完整解压 ZIP 到固定文件夹。
2. 双击 `Start-Agent-Board.cmd`，或用 Chrome / Edge 直接打开 `index.html`。
3. 无需安装 Node、Git、Python 或购买 API。关闭网页即可停止。

需要支持 dialog、File.text、replaceChildren 的现代浏览器。不能保证 Windows 1909 自带的旧浏览器可用，目标电脑仍需实际试运行。

## 功能

创建和重命名项目；项目间任务隔离；创建、编辑、删除任务；待办/进行中/待验收/已完成四列；拖放和状态菜单；高/中/低优先级；搜索筛选；归档与恢复；JSON 导出和导入；异常备份校验与损坏数据保护。

本包是独立的离线基础看板，不是原版 React/SQLite 完整程序的 Windows 移植。支持手动复制任务到 AI 网页；AI 自动执行、Codex/Claude CLI 接入、终端、自动开发和原版数据库导入尚未实现。移动到“进行中”只改任务状态。

## 数据和备份

数据保存在当前浏览器配置的本地存储中，**不是自动写入解压文件夹**。固定 HTML 的文件位置与浏览器；换位置、浏览器配置、无痕模式、清理浏览器数据可能导致看不到旧任务。

每次重要修改后点击“导出备份”，确认浏览器已下载 JSON。备份包括全部项目、任务及归档。换电脑时先导出，再在新环境导入。导入会替换当前离线版数据，应先备份；只有本离线版格式受支持。

保存失败时不会应用修改。存储损坏时禁止覆盖，可下载原始损坏数据并导入有效备份；不会自动清空损坏存储。每次保存前保留上一份原始存储。该副本仍属于浏览器存储，不能替代下载备份。

检测其他窗口写入或清空数据后，暂停本窗口保存与导入，请刷新再操作。写入前还会比对保存快照。此保护不是跨窗口事务锁；建议同一时间只用一个编辑窗口。离线版不会读取或修改原项目数据库、Git 仓库或账号信息，也不执行任务文字中的命令。

## 卸载

先导出备份，再删除解压文件夹即可。浏览器存储不会被程序自动删除。

## 0.1.2 新增操作

- **撤销上一步 / 恢复上一版**：恢复上一轮成功保存之前的整个看板（所有项目），先展示项目和任务数量并要求确认。这不是多级历史。再次点击可在最近两个有效版本之间切换；无有效上一版时按钮禁用。
- **下载上一版备份**：将上一个有效版本下载为 JSON，便于保留后再决定恢复。浏览器清理数据仍可能同时清掉当前和上一版，因此仍需下载备份。
- **损坏恢复**：若当前存储损坏而上一版有效，可直接恢复上一版；损坏的原始存储仍可在恢复前下载。
- **复制到待办**：复制任务标题、说明和优先级为新任务，放入当前项目的活动待办列；归档任务也可复制。原任务不变。
- **完成情况**：显示当前项目活动任务数、完成数、完成率和归档数。统计基于项目全部任务，不随搜索结果变化。
- **清除筛选**：一次清除搜索和优先级筛选，保留当前项目及归档视图。
- **未保存修改**：编辑表单点取消或按 Esc，存在修改时会询问是否放弃；保存失败提示直接显示在表单内。关闭浏览器或刷新不保留未保存草稿。

## 手动交接到 AI 网页

任务卡片点击“交接给AI”，看板会整理项目、标题、说明、验收条件和希望返回的结果格式。

1. 点击“复制任务说明”。浏览器不允许自动复制时，内容会被选中，手动 Ctrl+C。
2. 点击打开 ChatGPT 或 Claude，使用自己的账号。
3. 粘贴说明并自行发送。之后回到看板，手动更新任务描述与状态。

打开网页只打开链接，不把任务自动带入，不读取账号、不自动提交任务，也不自动把网页回复写回看板。这是人工辅助交接入口，不等于 M4 的 CLI 集成或 M5 的自动切换。说明中只包含看板已知内容，不会读取代码仓库或补造背景。

## 从 0.1.1 升级

先在旧版点击“导出备份”，确认 JSON 已下载；再解压新版并导入该 JSON。两版 schemaVersion 都为1，保持旧版备份兼容。不要在没有备份的情况下移动旧 HTML 或清理浏览器数据。
