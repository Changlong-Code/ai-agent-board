# 离线基础版 0.1.2 范围与数据安全审查

审查日期：2026-10-18。审查对象：当前 index.html 相比 0.1.1 的新增功能。结论：**通过静态代码审查，未发现 P1 数据安全阻断问题**。浏览器功能测试由独立 QA 记录；本结论不代表 Windows 10 1909 实机验收通过。

- 恢复上一版先验证完整数据结构、明确确认替换全部项目及任务，再经过统一存储快照检查；当前版本保留为上一份副本。损坏副本不能恢复，提示已说明。
- 下载上一版只在数据有效时进行；任务复制保留项目与内容，生成新标识及时间，重置到活动待办，不修改原任务。
- 搜索重置和完成率只读取状态；完成率按当前项目的活动任务计算，不把归档任务混入分母。
- 任务弹窗的取消按钮及 Escape 均对未保存修改要求确认；保存失败仍留在弹窗显示错误。
- AI 交接只生成只读说明，复制需要用户操作。外部链接明确由用户打开，使用 noopener/noreferrer，不携带任务文本；程序不会自动发送、登录或执行 AI。
- 原有字段校验、损坏保护、原始数据导出、快照比对及多窗口暂停保护保留；存储键与 schemaVersion 未变。localStorage 并非跨窗口事务数据库，仍应单窗口编辑并下载备份。

发布整理项：使用说明应更新为 0.1.2，并描述上一版恢复、任务复制与手动 AI 交接。旧原版工程的测试门禁和 Windows 移植状态不能据此标记完成。新版本若换 HTML 路径，浏览器可能不显示旧任务，升级前应导出、升级后导入 JSON。
